# THE BOMB IS NOT DEFUSED. IT IS GIVEN UP ON, AND THE GAME PAYS FOR IT.
#
# Defusing it is three switches in one order and then 58 turns of an 11-step
# loop while the dial hand sweeps 0..57 — a minute of real time spent watching
# a timer run out, for a key that opens one door. Giving up is four gestures.
#
# `hitok()` opens `if unibomdoor = 1: boomer()`, and `openstage()` sets
# `unibomdoor = 1`. So clicking OK on an untouched board is an immediate
# `boomer()`: bombblow.mov, then bombhelp.mov — and bombhelp.mov is not a
# cutscene, it is the game’s own help screen, twelve pages of "pics" with
# TRYAGAIN and GIVEUP in the corner. Its header names `giveup` as
# actionframe(1), and boomer's tail is:
#
#     if actionframe (1)
#         sendtoshop ("inven.shp", addinven ("bombkey"))
#         transfromflat ()
#
# — so clicking GIVEUP hands over the bomb key and leaves the flat, and
# clicking TRYAGAIN (or letting the movie end anywhere else) runs
# `closestage(); openstage()` and puts the whole board back. The key is all the
# door wants: c54 dumps it from the bag and does `setupprop("door",
# "c59-hallc")`. `bombphase = 2` was set by the click INTO the flat, so the
# lock is already off by the time we get here.
#
# Nothing is lost by blowing it up. `boomer()` never touches `playerdeath`, and
# the closing narration scores four ownerships — rubaiyat, realneck, painting,
# notebook — of which the bomb is none.
#
# AND IT IS NOT IN THIS VIEW. The ambush leaves you on Scene12/View29, because
# that is the end of Road38 and openscene turns you to it by hand; the bomb
# hotspot is the only object on Scene12/View31, two standpoints round the same
# ring. Measured as `nothing called "bomb" is clickable from here · clickable
# here: nothing`, which is the room telling the truth — the notebook above is a
# PROP and reachable from anywhere in the scene, the bomb is a view object and
# is not.
