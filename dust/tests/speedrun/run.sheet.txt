# =====================================================================
# THE SPEEDRUN — Dust: A Tale of the Wired West, any%
#
#   Copy the full run    the panel's own button, which is this file
#   Play                 runs it from the pointer
#
# One action per line. `#` is a comment, `;` separates actions on a line,
# `xN` repeats, `a, b, c` is one action per argument, `key: value` is an
# option. Every line takes `wait:`, `after:`, `budget:` and `gap:`.
#
# EVERY LEG LOADS THE SAVE IT STARTS FROM, which is the thing to
# understand about this file before reading it. The fifty-five legs below
# are the golden thread's rungs (docs/dust/thread.md), and a rung is
# independent of every other one: both its ends are saves the original
# player left on the disc, and it begins by loading the first of them.
#
# So this is not yet a continuous run and its total is not a time. It is
# the route, leg by leg, each one starting from a state that is exactly
# right — because a standpoint is not a state. Walking to where a save was
# taken puts the camera in the right place and leaves the cast wherever the
# world's clocks have carried it: `click(leroy)` failed that way, with
# Leroy in the cast and out of the view. `loadSave` settles the standpoint,
# the cast, the props, the phases and the clock at once.
#
# A leg that runs clean is a leg that can then be joined to its neighbour
# by deleting its `loadSave` — which is how this becomes a run.
#
# STATUS: TRANSCRIBED, and not yet driven. The gestures are read from the
# rungs (dust/tools/rung2sheet.ts) and the rungs are the only place they are
# written down; what a sheet has no grammar for is marked `# TODO`. It will
# stop somewhere, and the report names the line and prints where the game
# was standing. That is how it gets settled.
#
# THE VERBS THIS GAME ADDS
#
#   loadSave(D1E_001)     the disc's own saved games. NOT load(), which is
#                         a checkpoint this run wrote with save().
#   goto(10, 10)          walk to a grid cell of this room. Plans in the
#                         page, answers what interrupts the walk, re-plans
#                         from where it actually got to.
#   doorAt(x0,y0,x1,y1)   click a door's rectangle where the SCENE shows
#                         through it, then walk in.
#   takeInHand(mask)      a thing you are CARRYING into your hand, through
#                         the avatar panel. A thing lying in a ROOM is
#                         click(mask).
#   offer(ring)           hand it to whoever you are TALKING to — the
#                         inventory's 55555 plaque, and its picker.
#   give(bone, to, dog)   drop it on somebody standing in the room.
#   meet(jones)           walk to somebody wherever they have got to and
#                         get them talking. `accost` only turns where it
#                         stands; this walks.
#   talkOut([301,201])    leave a conversation, answering whichever of
#                         those replies is on the plaque — and fine if
#                         nobody is talking at all.
#
# And three the engine grew for this route: `accost` (Titanic's, now
# shared), `key(ArrowUp, until: visible.help)` — press until something is
# true — and `or` in a condition, because what a route waits for is
# usually two things: `until: choosing or global.trotterphase == 4`.
# =====================================================================

#   this leg ends at nite (10,10) facing south — D1E_001's own standpoint
# The one leg that starts cold: there is no save before the boot. Its
# films play before any set is opened, so there is no viewer while they
# run — which is why the skip asks for one rather than for `quiet` or
# `nomovie`, both of which read false through the whole opening. 183s of

# THE BOOT LEAVES A CONVERSATION OPEN, and this waits for it by name.
#
# A viewer is the first moment there is a game, not the last moment of
# the boot — `coldBoot` runs on past it — so the line after this one was
# asking before there was anybody to answer: "conversation ended before
# saying 104 (picked nothing)".
#
# Nobody clicks Leroy. `GANG.CST/0002 leroyidle ()` arms
# `hasattention (10)` and the boot hands over with `curattention =
# "leroy"` — that timer ALREADY RUN DOWN — so he accosts you as soon as
# the boot stops, from the standpoint it leaves you on: he stands at
# town.leroy1, cell (6,13), and you are at (6,14) facing north.
#
# So a run does not WAIT for it. `accost` makes the same gesture the
# timer would have made — `hasattention ()` fires `sendtoactor (target,
# mousedown (0))`, which is a click on him — and it turns to find him
# first if the boot left us facing somewhere else.
