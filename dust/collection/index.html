Play it offline

The 1995 game, not this port: the original DOS executable, run through DOSBox behind a front end that manages the setup. Four steps get it running.

  1. Download and install DBGL (DOSBox Game Launcher) — a front end for DOSBox.
  2. Download the archive below. Do not unzip it — DBGL does that itself.
  3. In DBGL, choose Profiles → Import… and pick the file you downloaded.
  4. Select the imported profile and press Play.
