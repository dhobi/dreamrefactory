Here you will find scanned and published material about the game. At the bottom of the page are the archives that let you play it offline in several languages (DOSBox).

Edition

The booklet

Folded into the box was a 32-page booklet: the manual, the controls, and several pages of period detail about the ship. Only the German one was ever scanned, so this is the one edition that has it. Click either half to turn a page.

This pressing's booklet was never scanned — only the German one is here.

Play it offline

The 1996 game, not this port: the original DOS executable, run through DOSBox behind a front end that manages the setup. Four steps get it running.

  1. Download and install DBGL (DOSBox Game Launcher) — a front end for DOSBox.
  2. Download one of the archives below. Do not unzip it — DBGL does that itself.
  3. In DBGL, choose Profiles → Import… and pick the file you downloaded.
  4. Select the imported profile and press Play.
