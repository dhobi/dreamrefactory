Adventure Out Of Time RE

RE is for reverse-engineered. This is not an emulation: it is a version of CyberFlix's DreamFactory engine implemented in JavaScript (TypeScript). Most of it already works, but this version is nowhere near the maturity of the original engine.
Play around, try the editors and report bugs straight to us on GitHub.
