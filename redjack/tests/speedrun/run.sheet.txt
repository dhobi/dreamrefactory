# title: RedJack — the whole game
#
# The machine suites' route (tests/machine/days/*.ts) as a sheet: the boot,
# then the seven days, to the end of the game.
#
#   npm run speedrun -w redjack            in node
#   /redjack/speedrun/                     in the workbench
#
# The moves are the suites' own (src/play/): goto() walks a room by its
# exits, click() finds a thing by the boot's hittest, answer() picks a plaque
# by the start of its text.
